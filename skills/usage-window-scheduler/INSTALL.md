# 一次安装，直接启用

在支持原生定时任务的 Codex 桌面聊天中发送：

```text
从 yogasamadhi/kk-skills 安装并启用 usage-window-scheduler，采用独立定时运行，其余使用默认配置。
```

如果已经在当前仓库中，发送“安装并启用 $usage-window-scheduler，使用默认时间和便宜模型，采用独立定时运行”即可。重新安装会复用已有任务。

安装完成会显示：**已安装并启用**、使用的时区和模型、每天的六个时间、任务 ID。机器需要在执行时保持运行并可联网；任务不会重置已有窗口或周额度。

## 给执行安装的 Agent

用户提交上述请求后，安装和启用都已获得授权，独立运行的模式也已明确。下载/安装文件后，立即读取 [SKILL.md](SKILL.md) 并执行，不要以“下轮可用”“请重启”“是否开启任务”结束安装。

1. 安装到该宿主支持的 Skill 搜索路径；若同名 Skill 已存在，先读现有文件并复用，不覆盖用户改动。当前本地源码安装可链接此完整目录，不必先发布到远端。
2. 从可信会话上下文读取用户时区，使用默认六个时间和经济型模型；自动检查原生工具与已有任务。不要要求用户手填配置。
3. 根据 `SKILL.md` 在同次安装中创建/更新/恢复独立任务。保持原生权限要求，不使用私有接口或修改调度数据库。没有原生工具时，报告安装受阻，不谎称已启用。
4. 回读实际任务并核对 ACTIVE、六个时间、实际模型/推理档位、通知设置和时区。只有匹配才返回“已安装并启用”。无需发送付费的立即测试请求。

仅把目录复制到磁盘，不会触发执行。这份安装入口由 Codex 连续编排“安装 + 启用”，而不是隐藏的文件钩子。若用户明确选择只安装文件、只预览或开发 Skill，遵循该范围。
