# 自研 Skill

每个 Skill 目录都可以独立安装。点击名称可查看对应的使用说明和随包资源。

| Skill | 用途 |
| --- | --- |
| [skill-doctor](skill-doctor/) | 审计 Skill 的结构、引用、安全信号与可移植性 |
| [skill-evaluator](skill-evaluator/) | 校验触发与行为评测用例，并对运行结果执行断言 |
| [ts-change-verification](ts-change-verification/) | 为 TypeScript 变更计算受影响 workspace 和验证命令 |
| [dependency-incident-audit](dependency-incident-audit/) | 将依赖安全公告映射到仓库中的直接依赖与锁文件证据 |
| [ts-release-readiness](ts-release-readiness/) | 检查 TypeScript/npm 包的发布就绪状态 |
| [docs-code-sync](docs-code-sync/) | 发现环境变量、CLI 参数、导出符号与文档之间的漂移 |
| [runtime-compatibility-probe](runtime-compatibility-probe/) | 评估包在 Node、Bun、Deno、浏览器和 Edge 中的兼容风险 |
| [miniapp-release-audit](miniapp-release-audit/) | 审查微信小程序、Taro 与 uni-app 的发布前风险 |
| [architecture-implementation-audit](architecture-implementation-audit/) | 将架构、ADR 与协议声明映射到实现、配置和测试证据 |
| [vendor-submodule-guardian](vendor-submodule-guardian/) | 检查 submodule 路径、gitlink、固定提交和 vendor 工作树状态 |
| [delivery-completeness-ledger](delivery-completeness-ledger/) | 用稳定任务 ID、验收标准和证据跟踪长期计划完成度 |
| [migration-parity-keeper](migration-parity-keeper/) | 审计旧系统到新系统的功能对等与切换准备度 |
| [agent-runtime-diagnostics](agent-runtime-diagnostics/) | 沿进程、认证、模型、推理、状态和 UI 链路诊断 Agent 可用性 |
| [desktop-release-matrix](desktop-release-matrix/) | 按平台和架构验证桌面安装包、校验和与冒烟证据 |
| [evidence-based-technical-decision](evidence-based-technical-decision/) | 使用项目约束、权重、官方证据与可逆性比较技术方案 |
| [product-engineering-loop](product-engineering-loop/) | 闭环执行产品诊断、实现、行为与视觉验证 |
| [usage-window-scheduler](usage-window-scheduler/) | 使用经济型模型在固定时间发送最小 Codex 请求，尝试启动订阅额度窗口。[安装与配置](../docs/usage-window-scheduler.md) |
